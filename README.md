#E-Commerce Web Automation Framework

## Tech Stack
- Selenium WebDriver
- Java
- TestNG
- Maven
- Page Object Model (POM)
- Jenkins
- Selenium Grid

## Project Structure
src/
  main/
  test/
    pageObjects/       ← POM classes
    testCases/       ← Test classes
    utilities/       ← Utility classes

## How to Run
1. Clone the repo
2. Run mvn test

## Test Cases Covered
- Login
- Product Search
- Add to Cart
- Checkout

## Framework Highlights
Page Object Model for maintainability
TestNG annotations for test management
Jenkins pipeline for CI/CD
Selenium Grid for parallel execution
